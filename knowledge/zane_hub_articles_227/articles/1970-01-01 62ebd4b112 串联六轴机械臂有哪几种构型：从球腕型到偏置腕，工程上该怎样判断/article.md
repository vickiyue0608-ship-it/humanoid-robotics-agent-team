# 串联六轴机械臂有哪几种构型：从球腕型到偏置腕，工程上该怎样判断

在工业现场讨论“串联六轴机械臂有哪几种构型”时，常常把两个概念混在一起：一个是机构几何构型，另一个是同一末端位姿对应的关节构型。按照 ISO 9787:2013 的定义，configuration 指的是“在任意时刻完全决定机器人形状的一组关节值”；而在工程选型语境里，大家更常说的是轴线如何布置、腕部是否偏置、是否属于典型 PUMA 类几何架构。先把这两个层面区分清楚，后面的判断才不会偏。 Source

先把问题讲清：什么叫“六轴”，什么叫“构型”

串联六轴机械臂，本质上是 6R 串联机构，也就是 6 个转动关节依次串接。工业上最常见的理解方式，是把前 3 轴看作位置臂，负责把腕心送到空间目标区域；后 3 轴看作姿态腕，负责末端姿态调整。CODESYS 对典型 6 轴关节机器人给出的描述非常直接：这种机器人具有六个旋转轴和六个自由度，并且常见形式中“三个定向轴相交于一点”，也就是通常说的腕心或腕部中心。 Source

如果只问“六轴机械臂有哪几种构型”，从机构设计和选型角度看，重点不是轴数本身，而是以下几个几何问题：

2、3 轴是否平行；

4、5、6 轴是否相交于一点；

腕部是否存在明显偏置；

中臂是否采用协作机器人常见的平行轴布局。

这几个问题，基本决定了逆解难度、奇异位形分布、空间包络、线缆布置、干涉风险，以及工艺可达性。

主流串联六轴机械臂，工程上主要看这 3 类结构构型

1. 垂直多关节 + 球腕/内联腕构型

这是工业现场最常见、也是最典型的串联六轴构型，很多资料会直接把它叫作PUMA 类构型、wrist-partitioned 结构或inline wrist 结构。Mecademic 对这类六轴机器人的描述很清晰：2 轴与 3 轴平行，1 轴与 4 轴垂直于 2、3 轴，5 轴垂直于 4、6 轴，而 4、5、6 三轴交于一点。 Source

这类构型之所以成为主流，不是因为结构看起来“像人手”，而是因为它在工程上有两个很大的优点：一是运动学分解清晰，位置与姿态可相对解耦；二是解析逆解成熟，控制器开发、离线编程、节拍优化都更容易落地。CODESYS 给出的 6 轴关节机器人 DH 参数表，也对应的是这一类典型工业架构。 Source

这类球腕/内联腕六轴，适合焊接、搬运、上下料、打磨、装配、码垛等大多数标准工业任务。需要注意的是，它的优势不在于“万能”，而在于综合平衡最好：控制简单、可达姿态多、生态成熟、维护经验丰富。

2. 偏置腕六轴构型

第二类是偏置腕六轴。它与球腕/内联腕的根本差异在于，4、5、6 轴不再严格交于同一个腕心点，腕部存在几何偏置。Mecademic 的资料明确提到，喷涂机器人通常不采用 inline wrist，因为腕部偏置可以带来更大的姿态能力。 Source

偏置腕的工程价值主要体现在三个方面。第一，避障能力更强，喷枪、焊枪、打磨头等长工具更容易绕开工件边界和本体干涉区；第二，姿态包络更灵活，对于深腔、斜面、包边等工艺动作更友好；第三，工艺接口布置更宽松，尤其是气管、电缆、涂料回路较多时更容易做腕部集成。

它的代价也非常明确：运动学模型更复杂，逆解、奇异性分析和轨迹连续性处理都比球腕型更难。国内公开专利检索中，也能直接看到“手腕偏置型串联机械臂”“手腕偏置型 6 轴机器人”的明确表述，这从侧面说明偏置腕已经是独立、稳定的一类工程构型。 SourceSource

3. 协作机器人常见的平行中臂六轴构型

第三类，是当前协作机器人中非常常见的一种六轴布置。Mecademic 对这类构型也做了专门归纳：1 轴与 2 轴相交且垂直，2、3、4 三轴平行，5 轴与 4、6 轴相交且垂直。它与传统 PUMA 类六轴外观上都像“六关节机械臂”，但几何本质并不一样。 Source

这类构型出现得越来越多，原因并不神秘：协作机器人更强调紧凑外形、关节一体化、近人工作空间布置以及中小负载工艺适配。因此，很多协作机型并不追求完全复刻传统工业机器人那套经典球腕架构，而是围绕轻量化、包络尺寸和关节模组化做重新取舍。

从应用上看，这类构型适合柔性上下料、轻载装配、检测、拧紧、实验室自动化等场景；但从纯机构学角度，它已经不属于传统教材里最标准的“PUMA 式球腕六轴”。

还有一种容易被忽略的“构型”：同一台机器人会有 8 种关节构型

如果讨论的不是“结构长什么样”，而是“同一个末端位姿，机器人能摆成几种姿势”，那么典型球腕/内联腕六轴通常又可以分成8 种关节构型。Mecademic 的资料指出，典型六轴工业机器人对同一末端位姿一般最多可有 8 组逆解，对应 8 种 configuration types。 Source

这 8 种构型，通常由 3 组二值条件组合而成：

front / back
elbow-up / elbow-down
flip / no-flip

2 × 2 × 2 = 8

换句话说，工程上常说的“前肘后肘”“翻腕不翻腕”，本质上都属于同一几何机构的不同关节构型分支，并不是不同的机械本体。这个区别在工艺调试时非常重要：很多现场问题并不是“机器人结构选错了”，而是“构型分支没选对”。 Source

为什么构型判断一定要结合奇异位形一起看

六轴构型一旦不同，奇异位形的出现条件和处理方式也会不同。对于典型球腕/内联腕六轴，Mecademic 给出的分类是三种：肩奇异、肘奇异、腕奇异。其中腕奇异通常对应 4 轴与 6 轴重合，肘奇异对应手臂拉直，肩奇异则与腕心落入 1、2 轴相关平面有关。 Source

速度层面上，这个问题通常写成：

q̇ = J⁻¹ v
v = [ẋ, ẏ, ż, ωx, ωy, ωz]ᵀ

当 det(J) → 0 时，系统逼近奇异位形，
为了维持末端笛卡尔速度，关节速度会迅速放大。

这也是为什么同样都是“串联六轴”，有的机型适合做连续轨迹涂胶与焊缝跟踪，有的更适合点到点搬运与轻装配。构型不是纸面分类，而是直接决定控制难度和工艺稳定性的结构因素。 Source

选型时，真正该问的不是“有哪几种”，而是“当前工艺适合哪一种”

从项目实践角度，判断串联六轴机械臂构型是否合适，建议优先核对 5 个问题：

1. 工具姿态要求是不是持续变化

如果工艺需要连续大范围翻腕，尤其是喷涂、包边、深腔打磨，偏置腕往往比标准球腕更有优势；如果以标准抓取、搬运、焊接为主，球腕/内联腕通常更稳妥。 Source

2. 目标区域是不是靠近本体、夹具或立柱

接近本体时，肩奇异和基座干涉常常先暴露；目标区域很深时，腕部偏置与工具长度会显著影响可达性。ISO 9787:2013 对 base coordinate system、tool coordinate system、TCP 等坐标定义的统一，正是为了避免在这类评估中把“可达”与“可用”混为一谈。 Source

3. 控制器是否需要解析逆解和稳定的离线编程体验

标准球腕六轴的优势，是运动学边界清晰、行业软件支持成熟；结构越偏离经典球腕，往往越依赖控制器算法能力与厂商标定质量。 SourceSource

4. 是否需要在同一点位上切换多套关节姿态

对于装配、避让、穿孔、伸入式抓取等任务，同一 TCP 位姿下能否在 front/back、elbow-up/down、flip/no-flip 之间切换，往往比静态负载参数更关键。 Source

5. 是否接受在奇异附近降速、停顿或偏离路径

不同厂家对奇异位形的控制策略并不相同。有的允许略微偏离理想笛卡尔轨迹来避开奇异，有的坚持路径不偏离、但在穿越奇异时允许短暂停顿。构型选择，最终必须和控制策略一起看。 Source

结论：串联六轴机械臂，到底有哪几种构型

如果从机构几何构型来回答，串联六轴机械臂在工程上可以概括为 3 个主流类别：

垂直多关节 + 球腕/内联腕构型：最经典、最主流，逆解成熟，适合绝大多数标准工业应用；

偏置腕六轴构型：更强调姿态包络与避障能力，适合喷涂、深腔、复杂轨迹等工艺；

协作型平行中臂六轴构型：更强调轻量化与紧凑布置，常见于协作机器人。

如果从同一末端位姿对应的关节构型来回答，那么典型球腕六轴通常又可分成 8 种姿态分支，也就是 front/back、elbow-up/down、flip/no-flip 的组合。

因此，工程上更准确的说法不是“六轴机械臂只有几种构型”，而是：六轴机械臂至少要同时从机构构型和关节构型两个层面去判断。前者决定本体能力边界，后者决定工艺路径能否真正跑得通。
