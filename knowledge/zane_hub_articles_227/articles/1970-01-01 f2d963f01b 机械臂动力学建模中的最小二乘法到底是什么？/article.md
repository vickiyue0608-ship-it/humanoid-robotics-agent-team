# 机械臂动力学建模中的最小二乘法到底是什么？

引言

机械臂动力学参数辨识一直是机器人控制领域的核心技术难题。无论是工业机器人的高速高精度运动控制，还是协作机器人的柔顺交互，都离不开精确的动力学模型。最小二乘法作为参数辨识的经典方法，在机械臂动力学建模中扮演着关键角色。本文将从工程实践角度，深入探讨最小二乘法在机械臂动力学参数辨识中的应用原理、实施步骤和技术要点。

为什么需要动力学参数辨识？

机械臂的动力学模型描述了关节力矩与运动状态（位置、速度、加速度）之间的关系。精确的动力学模型是实现以下目标的基础：

高精度轨迹跟踪：通过前馈补偿减少跟踪误差

力矩预测与优化：提前计算所需驱动力矩，优化能耗

碰撞检测：基于力矩残差判断外部碰撞

柔顺控制：实现人机协作的安全交互

然而，机械臂的惯性参数（质量、转动惯量、质心位置）、摩擦参数（库伦摩擦、粘性摩擦）等动力学参数，无法通过直接测量精确获得。CAD模型提供的理论值往往与实际装配后的系统存在显著偏差。因此，基于实验数据的参数辨识成为获取精确动力学参数的唯一有效途径。

机械臂动力学建模基础

拉格朗日方程建模

拉格朗日法是机械臂动力学建模的主流方法，从能量角度建立系统的运动方程。对于n自由度串联机械臂，其动力学方程可表示为：

τ = M(q)q̈ + C(q,q̇)q̇ + G(q) + τf

其中：

τ：关节驱动力矩向量

M(q)：惯性矩阵，描述关节加速度与力矩的关系

C(q,q̇)：科里奥利力和离心力项

G(q)：重力项

τf：摩擦力矩

这个方程清晰地展示了力矩如何由四个部分组成：加速度引起的惯性力、速度引起的离心力和科里奥利力、重力以及摩擦力。

参数线性化处理

动力学方程虽然在关节变量上是非线性的，但相对于待辨识的动力学参数却是线性的。这是应用最小二乘法的关键前提。通过参数重组，动力学方程可改写为线性形式：

τ = W(q,q̇,q̈)θ

其中：

W：观测矩阵（Observation Matrix），仅与运动状态有关

θ：待辨识的动力学参数向量

最小惯性参数集

并非所有动力学参数都对关节力矩产生独立影响。通过参数重组，可以获得一组最小惯性参数集，这些参数：

数量最少

相互独立

完整描述动力学特性

例如，对于ABB IRB2600机器人前三轴，经过重组后可得到21个最小惯性参数，其中15个为惯性参数，6个为摩擦参数。

最小二乘法的核心原理

最小二乘法（Least Squares Method）的核心思想是：找到一组参数估计值，使得模型预测力矩与实际测量力矩之间的误差平方和最小。

标准最小二乘算法

采集机械臂在N个不同时刻的数据，将线性化的动力学方程写成矩阵形式：

Γ = Wθ + e

其中：

Γ：N×n的力矩测量矩阵（n为关节数）

W：N×p的观测矩阵（p为参数个数）

e：测量误差

最小二乘解为使目标函数最小的参数估计：

θ̂ = argmin ||Wθ - Γ||²

通过求解正规方程，可得最小二乘估计：

θ̂ = (WᵀW)⁻¹WᵀΓ

这个公式的几何意义是：在参数空间中找到一个点，使得观测矩阵张成的子空间与测量力矩向量的距离最小。

加权最小二乘法

实际应用中，不同关节的力矩测量噪声水平不同。加权最小二乘法（Weighted Least Squares, WLS）通过引入权重矩阵Σ，对不同测量赋予不同权重：

θ̂WLS = (WᵀΣ⁻¹W)⁻¹WᵀΣ⁻¹Γ

权重矩阵通常由各关节力矩测量方差的倒数构成，测量噪声大的关节获得较小权重，提高参数估计的鲁棒性。

激励轨迹优化设计

激励轨迹的质量直接影响参数辨识精度。优秀的激励轨迹应充分激发机械臂的动力学特性，同时满足运动约束。

傅里叶级数轨迹

傅里叶级数因其周期性、可微性和参数化优势，成为激励轨迹的主流选择：

qi(t) = qi0 + Σ[al,i·ωf·l·sin(ωf·l·t) - bl,i·ωf·l·cos(ωf·l·t)]

其中：

N：谐波项数，通常取5

ωf：基频，如0.1Hz

al,i, bl,i：待优化的傅里叶系数

qi0：关节角度偏移量

优化目标与约束

激励轨迹优化以最小化观测矩阵条件数为目标：

min cond(W) = σmax(W) / σmin(W)

条件数反映了观测矩阵的数值稳定性。条件数越小，参数辨识结果对测量噪声越不敏感。

同时需满足约束条件：

关节位置限制：qmin ≤ q(t) ≤ qmax

关节速度限制：|q̇(t)| ≤ q̇max

关节加速度限制：|q̈(t)| ≤ q̈max

关节力矩限制：|τ(t)| ≤ τmax

MATLAB优化工具箱中的fmincon函数可高效求解这一非线性约束优化问题。

数据采集与预处理

数据采集要求

驱动机械臂沿优化后的激励轨迹运动，以足够高的采样频率（如1000Hz）采集：

关节角度 q

关节力矩 τ（通过电流传感器获取）

为减少随机误差，可重复多次采集并求平均值。采集20秒运动过程，通常可获得20000组原始数据。

滤波与差分处理

原始数据存在测量噪声和毛刺，必须经过预处理：

力矩信号滤波：采用卡尔曼滤波器对力矩信号降噪平滑，相比五点三次平滑法具有更好的滤波效果和更低的数据失真

速度和加速度计算：关节角度经低通滤波后，通过数值差分获得角速度和角加速度。直接差分会放大噪声，因此差分后需再次滤波

数据降采样：为提高计算效率，可从20000组数据中均匀提取2000组用于辨识，既保证数据充分性，又避免冗余数据的干扰

参数估计与验证

求解最小二乘问题

将预处理后的数据代入线性化动力学方程，构建观测矩阵W和力矩向量Γ，通过加权最小二乘法求解参数：

% 构建权重矩阵
sigma =diag(var(Gamma,0,1));
Sigma =kron(eye(n_joints), sigma);

% 加权最小二乘求解
theta_WLS =(W'*inv(Sigma)* W)\(W'*inv(Sigma)* Gamma);

对于ABB IRB2600机器人，辨识结果的绝对误差大部分在0.1-0.3之间，相对误差在5%以内，表明辨识精度良好。

模型验证

参数辨识完成后，必须通过不同于激励轨迹的验证轨迹检验模型精度：

设计新的验证轨迹（同样采用傅里叶级数但系数不同）

采集验证轨迹下的实际力矩τm'

使用辨识参数预测力矩τp = W'θ̂

计算均方根误差（RMS）评估精度：

RMS = sqrt(Σ(τp - τm')² / N)

实验表明，基于加权最小二乘法辨识的参数，能够将力矩预测误差控制在5%以内，验证了方法的有效性。

改进方法与工程实践

递归最小二乘法

对于需要在线更新参数的应用（如负载变化、磨损补偿），递归最小二乘法（Recursive Least Squares, RLS）可实现参数的实时估计：

θ̂(k+1) = θ̂(k) + K(k)·[τ(k) - W(k)θ̂(k)]

其中K(k)为增益矩阵，随时间递推更新。RLS避免了每次都重新求解大规模矩阵方程，适合实时应用。

智能优化算法融合

传统最小二乘法可能陷入局部最优。近年来，将最小二乘法与智能优化算法（如粒子群算法PSO、遗传算法GA）结合，成为研究热点：

用加权最小二乘法获得初始解

以初始解为中心设定搜索边界（如±10%）

采用智能算法在边界内全局搜索

获得更精确的参数估计

实验表明，基于随机权重粒子群算法（RWPSO）的改进方法，相比标准WLS-PSO算法，关节2和关节3的辨识精度分别提高10.5%和11.5%。

摩擦模型精细化

简单的库伦+粘性摩擦模型在低速和换向时存在较大误差。更精细的摩擦模型包括：

静摩擦：静止时的最大静摩擦力

Stribeck效应：低速时摩擦力随速度下降的现象

温度补偿：考虑关节温度对摩擦的影响

这些因素可通过扩展参数向量和观测矩阵纳入辨识框架。

实际应用案例

案例：UR5协作机器人

Universal Robots的UR5协作机器人采用参数辨识技术实现高精度力矩控制：

辨识参数：28个惯性参数 + 12个摩擦参数

激励轨迹：7阶傅里叶级数，周期20秒

辨识精度：力矩预测误差RMS < 0.5 Nm

应用效果：实现无传感器碰撞检测，灵敏度提升40%

案例：珞石xMate机械臂

国产协作机器人珞石xMate通过动力学参数辨识优化控制性能：

优化算法：WLS + MATLAB fmincon

建模方法：牛顿-欧拉递推算法

辨识周期：每次负载变化后自动重新辨识

控制提升：轨迹跟踪误差降低60%，重复定位精度达±0.02mm

技术挑战与解决方案

挑战1：测量噪声干扰

问题：传感器噪声、电气干扰导致力矩测量不准确

解决方案：

采用高精度力矩传感器或电流传感器

多次重复实验求平均

采用卡尔曼滤波或小波去噪

加权最小二乘法降低噪声影响

挑战2：参数时变性

问题：温度变化、磨损、负载改变导致参数漂移

解决方案：

定期重新辨识参数

采用递归最小二乘在线更新

建立参数-温度关联模型

根据负载变化触发自动辨识

挑战3：计算复杂度

问题：大规模矩阵求逆计算量大，实时性差

解决方案：

数据降采样减少矩阵规模

采用QR分解或奇异值分解提高数值稳定性

利用观测矩阵稀疏性优化计算

多核并行计算加速求解

未来发展趋势

深度学习与最小二乘融合

神经网络可学习动力学模型的非线性特性，与最小二乘法结合：

神经网络拟合难以建模的非线性项

最小二乘法辨识可解释的物理参数

物理信息神经网络（PINN）保证物理一致性

自适应参数辨识

根据运动状态自动调整辨识策略：

高速运动时重点辨识惯性参数

低速运动时重点辨识摩擦参数

负载变化时快速更新质量相关参数

多机器人协同辨识

多台同型号机器人共享辨识结果：

统计多台机器人参数分布

识别系统误差和随机误差

建立参数不确定性模型

提高辨识鲁棒性

小结

最小二乘法作为机械臂动力学参数辨识的核心方法，具有数学原理清晰、计算高效、易于实现的优点。其成功应用需要：

精确建模：基于拉格朗日或牛顿-欧拉法建立动力学模型，完成参数线性化和最小参数集提取

轨迹优化：采用傅里叶级数设计激励轨迹，通过条件数优化充分激发动力学特性

数据处理：高频采集运动数据，通过滤波和差分获得高质量输入

算法改进：根据应用需求选择加权最小二乘、递归最小二乘或智能优化算法融合方案

充分验证：通过不同轨迹验证辨识精度，确保模型泛化能力

随着机器人向高速化、智能化、协作化方向发展，动力学参数辨识技术也在不断演进。深度学习、自适应控制、多机器人协同等新技术的融入，将进一步提升参数辨识的精度和智能化水平，为机器人实现更复杂、更精确的运动控制提供坚实基础。
