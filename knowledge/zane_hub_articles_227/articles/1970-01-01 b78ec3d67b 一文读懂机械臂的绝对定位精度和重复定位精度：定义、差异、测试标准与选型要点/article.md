# 一文读懂机械臂的绝对定位精度和重复定位精度：定义、差异、测试标准与选型要点

在机械臂选型、工艺评估和产线验收中，“精度”几乎是每个项目都会谈到的词。但工程现场最容易被混用的，恰恰是两个最基础的指标：绝对定位精度和重复定位精度。

很多项目在前期只盯着样本手册上的“±0.02 mm”“±0.05 mm”，后期真正进入离线编程、工装互换、孔位加工或视觉引导补偿时，才发现机器人“回得很稳”，但“打得不准”。问题往往不在机器人失控，而在于一开始就把两个指标当成了同一件事。

这篇文章把这两个概念、它们的测试逻辑、工程意义以及选型中的常见误区拆开说明。

先说结论：两者不是一回事

重复定位精度，衡量的是机器人在同样条件下，多次返回同一目标点时的一致性。

绝对定位精度，衡量的是机器人实际到达的位置，与理论指令位置之间的偏差大小。

通俗地说：

重复定位精度看的是“每次回来的离散程度”

绝对定位精度看的是“实际位置离目标位置有多远”

因此，完全可能出现这样一种典型情况：机器人每次都停在几乎同一个地方，但这个地方离真正目标点始终差了几毫米。这类机器人，重复定位精度可以很好，绝对定位精度却并不高。

什么是重复定位精度

重复定位精度（Repeatability）关注的是离散性。

如果机械臂连续多次执行同一条指令，末端 TCP 每次落点都非常接近，说明它的重复性好。对大量示教式应用而言，这个指标非常关键，例如点焊、搬运、上下料、喷涂、码垛等。因为这类工艺的本质不是“第一次就精确命中理论坐标”，而是“只要教过一次，后面每次都稳定回到那个工艺点附近”。

这也是为什么绝大多数机器人样本首先公布的是重复定位精度，而不是绝对定位精度。重复性更容易成为稳定、统一、可比较的指标，也更符合大量传统工业场景的使用方式。

什么是绝对定位精度

绝对定位精度（Absolute Accuracy）关注的是系统误差。

当程序里给出一个理论坐标点，机器人实际到达的位置与该点之间的差，就是绝对定位误差。这个误差可能来自连杆尺寸偏差、减速器和关节零位误差、装配公差、基座安装误差、负载挠度、TCP 标定误差、温漂，以及控制器补偿模型是否完整。

对下列场景而言，绝对定位精度往往比重复定位精度更重要：

离线编程后直接上线

钻孔、铣削、切边、去毛刺等机器人加工

多工位夹具切换与机器人互换

测量、检测、轨迹跟随

高要求的视觉引导抓取与装配

ABB 在其 Absolute Accuracy 资料中提到，虚拟机器人与真实机器人之间的偏差通常可达到 8–15 mm；通过绝对精度补偿方案，可在整个工作范围内保持约 0.5 mm 的可维护精度。这组数据很能说明问题：未做补偿时，离线模型与现场实机之间往往存在明显落差，而补偿和校准的价值，就在于把这种系统误差压缩到可用于工艺的范围内。来源

为什么“重复性很好”不等于“绝对位置很准”

这是机械臂应用中最常见的认知误区。

从误差性质上看，重复定位精度更多反映的是随机误差和短期一致性；绝对定位精度则更容易受到系统误差支配。系统误差一旦存在，机器人完全可以“稳定地错”。

典型原因包括：

1. 运动学参数存在偏差

连杆长度、公称轴系、关节零点和安装基准在实际制造与装配中都存在偏差。模型里是理想尺寸，实机却不是理想体。

2. 负载引起的结构挠度没有被充分补偿

末端工具变长、负载加大、姿态变化后，结构挠度会改变 TCP 的真实位置。ABB 的 Absolute Accuracy 方案明确把机械特性补偿和负载挠度补偿作为核心内容之一。来源

3. 基座、工装和 TCP 标定误差被混入“机器人精度”

现场经常把系统级误差全部算到机器人头上。实际上，机器人本体、安装底座、夹具、工件基准、工具中心点、视觉坐标系之间，任意一个环节出偏差，都会表现为“绝对位置不准”。

4. 温度、速度、方向和姿态改变后，误差分布也会变化

误差并不是一个固定常数，它和姿态、方向、速度、负载、工作区位置都有关系。这也是为什么单看样本中的一行参数，远远不够。

ISO 9283 到底规定了什么

在工业机器人性能测试中，最常被提到的标准之一就是ISO 9283:1998。该标准全称为Manipulating industrial robots — Performance criteria and related test methods，由 ISO/TC 184/SC 2 制定，第二版替代了 1990 版及其修订件。来源

标准的核心不是简单给一个“精度数字”，而是规定如何描述和测试机器人性能。公开可见的标准范围中，明确列出了多项性能特性，包括：

pose accuracy（位姿精度）

pose repeatability（位姿重复精度）

distance accuracy / repeatability（距离精度 / 重复精度）

path accuracy / path repeatability（轨迹精度 / 轨迹重复精度）

path velocity characteristics（轨迹速度特性）

static compliance（静态柔顺性）

weaving deviations（摆动偏差）等

这意味着，工程上谈“机器人精度”时，实际上至少要先说清楚：到底讨论的是点位、距离、轨迹，还是姿态。不同工艺最关心的精度对象并不相同。来源

根据 RoboDK 对 ISO 9283 的工程化说明，位置精度和重复精度测试通常在所谓的ISO test cube内进行；常见做法是在5 个不同构型下分别进行30 次测量。这个流程有利于形成统一测试口径，但对现代机器人来说，仅靠少量点位并不足以完整表征全工作空间的绝对误差分布，因此在高精度应用中，往往还需要更密集的标定和验证数据。来源

为什么厂家样本多写重复定位精度，而不强调绝对定位精度

这并不是“厂家回避问题”，而是因为两个指标的应用前提不同。

重复定位精度更适合标准化公布

重复定位精度通常更稳定，也更容易在统一条件下给出公称值，因此适合写进样本手册，作为跨型号比较的基础指标。

绝对定位精度强依赖具体条件

绝对定位精度会受到以下因素明显影响：

是否做过出厂标定与现场重标定

负载大小与负载重心

TCP 是否重新标定

基座是否重装

工装坐标系是否变化

温度与使用时间

实际工作区是否靠近奇异区或柔弱姿态区

ABB 的 Absolute Accuracy 资料还特别强调了机器人“可互换性”与“整个生命周期内的可维护精度”，这本质上说明：绝对定位精度不是一次性指标，而是需要通过标定、补偿、维护与验证来持续保持的系统能力。来源

绝对定位精度通常靠什么提升

绝对精度改善，本质上不是“把机器人调得更听话”，而是让控制模型更接近真实机器。

常见做法包括：

1. 机器人几何标定

通过激光跟踪仪、光学测量系统等设备，识别机器人真实运动学参数，并建立补偿模型。

2. 负载与挠度补偿

负载变化会直接改变末端位置。对于长工具、大偏心负载或不同姿态下的工艺点，这一步非常关键。

3. TCP、基座和工装坐标的重建

很多项目的绝对误差，并不是机器人本体能力不足，而是坐标链管理混乱。TCP、Base、WorkObject、Vision Frame 任何一个定义不准，都会让绝对精度恶化。

4. 周期性复核与维护

减速器更换、电机维护、夹具调整、底座挪动后，都应复核绝对精度。ABB 的资料把这些维护场景明确纳入 Absolute Accuracy 的价值范围，这一点很值得现场工程团队重视。来源

工程现场最容易踩的 5 个坑

1. 用重复定位精度替代绝对定位精度

这是最常见的问题。样本上的 ±0.02 mm，通常不能直接理解为“机器人能把任意空间点都打到 ±0.02 mm”。

2. 只验机器人本体，不验系统级精度

真正决定结果的，是机器人 + 末端工具 + 工装夹具 + 基座 + 工件基准 + 坐标系转换的整体误差链。

3. 离线编程项目却没有绝对精度方案

如果项目目标是“程序离线生成、现场少示教甚至免示教”，那就不应只问重复定位精度，而应直接问：

是否支持绝对精度标定

是否提供补偿数据

精度保证覆盖哪些工作区域和负载条件

维护后如何复核精度

4. 只看空载，不看真实工况

工具长度、重心偏置、速度、姿态切换都会改变量值。空载测试合格，并不代表实际工艺也合格。

5. 把一次测得的精度当成终身能力

绝对定位精度是维护出来的，不是一次验收后永久不变的静态标签。

项目选型和验收时，建议至少问清这 6 件事

样本给出的到底是重复定位精度，还是绝对定位精度。

精度数值对应的是哪种标准和测试方法，是否参考 ISO 9283。

测试条件是什么：负载、速度、姿态、工作区、温度、TCP 长度。

是否支持出厂绝对精度标定、现场复标和维护后重建。

离线编程、工装互换和机器人互换时，是否有精度保证机制。

验收时是否做工艺区域内的系统级点位验证，而不是只看厂内样本参数。

结语：先分清“稳不稳”，再分清“准不准”

机械臂精度讨论里，最怕的是把两个不同问题混成一个问题。

重复定位精度回答的是：机器人回不回得稳定。

绝对定位精度回答的是：机器人打不打得准确。

对于传统示教工艺，重复定位精度往往更重要；但对离线编程、机器人加工、测量检测和高一致性制造，绝对定位精度才是真正决定项目上线难度和长期维护成本的关键指标。

真正成熟的工程判断，不是看到一个“±0.0X mm”就放心，而是先问清楚：这个数字到底描述的是哪一种能力，它在什么条件下成立，对当前工艺是否真的有意义。
