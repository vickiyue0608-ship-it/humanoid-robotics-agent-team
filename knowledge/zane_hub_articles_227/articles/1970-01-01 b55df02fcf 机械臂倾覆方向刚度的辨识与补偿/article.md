# 机械臂倾覆方向刚度的辨识与补偿

上一篇机械臂刚度补偿有哪些方向？梳理了机械臂刚度补偿的几条主要路线，有读者留言问到「倾覆方向的刚度补偿及辨识」。这个问题提得很准——倾覆方向刚度确实是工程实践中最容易被忽视、但在大臂展、重载场景下影响精度最显著的一个维度。今天就这个话题展开聊聊，谈谈物理本质、建模思路和工程实现。

一、先把概念捋清楚：倾覆刚度≠扭转刚度

在上篇的框架里，关节刚度矩阵Kθ通常被简化为对角阵，每个元素代表一个关节的扭转刚度（绕关节轴方向的抗扭能力）。这是VJM（虚关节法）最常见的简化假设，在很多场景下够用。

但现实中，关节的弹性变形并不只是绕轴扭转这一个方向。关节在承受外部载荷时，还会在垂直于关节轴的平面内发生倾斜，这就是倾覆变形。

以六轴机械臂的J1腰关节为例：

扭转变形：腰部在水平面内因驱动力矩不足产生的角度滞后，影响末端在XY平面的定位。

倾覆变形：大臂伸展后，末端负载产生的倾覆力矩（绕水平轴的弯矩）使腰部底部轴承组发生倾斜，导致末端在Z方向和俯仰方向出现附加偏差。

两者的量级关系在工程中有一个常见规律：同一关节的扭转刚度通常是倾覆刚度的数倍甚至数十倍。谐波减速器的扭转刚度有厂商标注参数可查（约10⁴~10⁵ N·m/rad），但其倾覆刚度往往取决于输出轴的轴承配置，设计不当时会成为整机精度的短板。

二、倾覆方向刚度的力学本质

2.1 倾覆力矩从何而来

串联机械臂的结构决定了它天然是一个悬臂结构。大臂展开时，末端负载的重力对基座关节形成的弯矩随臂展线性增大：

M_overturn = F_load × L_arm  (N·m)

以一台6轴机械臂、臂展1.4m、负载20kg为例，末端对J1关节的倾覆力矩约为：

M = 20kg × 9.8m/s² × 1.4m ≈ 274 N·m

这个力矩作用在J1关节的轴承组上，使关节产生倾斜角δ_t：

δ_t = M_overturn / K_t

其中K_t为倾覆刚度（N·m/rad 或 N·m/mrad）。若K_t = 5×10⁵ N·m/rad，则倾覆角约为0.55 mrad，对1.4m臂长产生的末端位移约为0.77mm。这个量级在±0.1mm精度要求下是不可忽略的。

2.2 哪些关节最值得关注

倾覆刚度问题并非对所有关节同等重要，需要结合力矩分析判断：

关节

倾覆力矩来源

典型量级

对末端精度影响

J1（腰）

全臂展产生的径向弯矩

最大（百至千N·m）

全局性影响，放大系数最大

J2（大臂）

前端各连杆+负载重力矩

次大

主要影响Z方向精度

J3（小臂）

前端连杆+负载弯矩

中等

影响俯仰精度

J4-J6（腕）

末端工具+负载力矩

较小

影响末端姿态精度

重载机械臂（如汽车焊接机器人、大型板件搬运机器人）的J1关节通常采用交叉滚子轴承或四点接触球轴承，其倾覆刚度是整机倾覆精度的主控因素。协作机器人因臂展小、负载轻，J1倾覆刚度问题相对不突出，但在大载荷末端执行器场景下同样需要关注。

2.3 轴承构型对倾覆刚度的影响

关节内的轴承配置是决定倾覆刚度的关键：

单薄壁轴承方案：结构紧凑，轴向长度短，但倾覆刚度低，适合腕部轻载关节。

轴向间距配对轴承方案：两套轴承沿轴向分开布置，等效力臂L_brg增大，倾覆刚度近似为：

K_t ≈ 2 × K_axial × (L_brg/2)²

通过增大L_brg，可以在不改变单套轴承刚度的前提下显著提升倾覆刚度。ABB IRB 6660等重载机器人采用双轴承特殊布置，就是基于这一原理。

三、倾覆刚度的建模方法

3.1 扩展VJM：从单DOF到多DOF虚关节

传统VJM将每个关节建模为一个扭转弹簧，关节刚度矩阵为：

Kθ = diag(k₁, k₂, ..., k₆)   (仅扭转)

考虑倾覆柔性后，每个关节需要扩展为多自由度弹性单元。以一个完整的关节弹性模型为例，需要描述6个方向的弹性：

关节i的广义柔性矩阵 Cᵢ（6×6）：

[δ_x  ]   [c_xx  c_xy  c_xz  c_xrx  c_xry  c_xrz]   [F_x ]
[δ_y  ]   [c_xy  c_yy  c_yz  c_yrx  c_yry  c_yrz]   [F_y ]
[δ_z  ] = [c_xz  c_yz  c_zz  c_zrx  c_zry  c_zrz] × [F_z ]
[δ_rx ]   [c_xrx c_yrx c_zrx c_rxrx c_rxry c_rxrz]   [M_x ]
[δ_ry ]   [c_xry c_yry c_zry c_rxry c_ryry c_ryrz]   [M_y ]
[δ_rz ]   [c_xrz c_yrz c_zrz c_rxrz c_ryrz c_rzrz]   [M_z ]

对于旋转关节，主对角线上的c_rzrz = 1/k_torsion（扭转柔度），而c_rxrx、c_ryry对应倾覆柔度（沿两个倾覆轴方向）。

实际工程中，常做如下简化：

保留扭转柔度（对角元素c_rzrz）

保留倾覆柔度（对角元素c_rxrx、c_ryry）

忽略轴向柔度和交叉耦合项（通常为小量）

这样，每个关节由3个独立刚度参数描述：扭转刚度k_θ、两个倾覆方向刚度k_tx、k_ty。

3.2 笛卡尔空间的倾覆刚度映射

关节空间倾覆刚度通过扩展雅可比矩阵映射到末端笛卡尔空间。考虑倾覆柔性后，末端柔度矩阵变为：

C_cart = Σᵢ [ Jᵢᵀ · Cᵢ · Jᵢ ]

其中Jᵢ为第i关节对末端位姿的影响矩阵。倾覆柔性的贡献体现在笛卡尔柔度矩阵的平动-转动耦合项上——这是一个容易被忽视的物理现象：关节的倾覆角变形，经过后续连杆的放大，会同时产生末端的平动偏差和姿态偏差。

以J1倾覆变形为例，倾覆角δ_t在臂长L处产生的末端位移误差近似为：

Δp ≈ δ_t × L_total

对于臂长1.5m、倾覆角0.5mrad的情形，末端位移误差约0.75mm，且随机械臂姿态变化（臂展不同，L_total不同）。

3.3 非线性刚度特性

需要特别说明的是，倾覆刚度并非严格的线性常数。几种典型的非线性来源：

预紧力非线性：轴承预紧力设定后，在小载荷范围内表现为较高刚度（赫兹接触弹性），在大载荷下进入线性区。力矩超过一定阈值后，接触区面积改变，刚度系数下降。

间隙非线性：轴承游隙存在时，小载荷阶段表现为近零刚度（"死区"），载荷增大到消除游隙后才呈现正常刚度。这种非线性在轻载精密作业时影响最大。

传动链柔性耦合：谐波减速器的输出轴不仅承受扭转，也承受弯矩和轴向力。弯矩作用下，柔轮的变形对扭转传动精度产生耦合影响，表现为刚度矩阵的非对角耦合项。

在精度要求≤0.3mm的场合，非线性效应不能忽略，需要分段线性化或采用数据驱动方法处理。

四、倾覆刚度的辨识方法

辨识是补偿的前提。倾覆刚度的辨识比扭转刚度更复杂，根本原因在于：很难单独激励倾覆方向的变形，而不同时引起扭转和其他方向的变形。下面介绍几种工程上可行的方法。

4.1 静态加载-激光跟踪仪法

这是目前工程精度最高的方法。

基本思路：在机械臂末端施加已知的外力（砝码或测力装置），利用激光跟踪仪测量末端6D位姿（3个平动+3个转动），通过最小二乘法辨识关节柔性参数。

具体步骤：

步骤1：构型选取

选取若干辨识构型，要求在各关节处产生可观测的倾覆力矩。对于N关节机械臂，理论上至少需要N×3个线性无关测量方程（3个方向的平动误差），实践中建议采集N×5以上的测量点以提高辨识精度。

构型选择的原则：

各构型应使机械臂在不同的俯仰角和伸展距离下工作

避免接近奇异位形（雅可比矩阵行列式趋零）

尽量覆盖工作空间的外围区域（倾覆力矩大，可观测性好）

步骤2：力矩计算

施加质量为m的砝码，末端法兰的受力为 F = mg，对各关节产生的倾覆力矩通过机器人静力学方程计算：

M_overturn_i = Jᵢᵀ · F_end   （关节i处的广义力矩向量）

需要注意：倾覆力矩不仅来自末端砝码，机械臂各连杆的自重同样贡献倾覆力矩。若要提高辨识精度，需同时建立包含连杆重力的完整力矩模型。

步骤3：变形测量

激光跟踪仪（Leica AT9x0或类似设备）以±15μm+6μm/m的精度测量末端靶标位置。通过比较加载前后的位姿差，获得末端6D变形量：

[Δx, Δy, Δz, Δrx, Δry, Δrz]ᵀ = X_loaded - X_unloaded

注意：扣除负载引起的运动学误差（几何标定残差），只保留弹性变形分量。通常需要先完成DH参数标定，再进行刚度辨识。

步骤4：最小二乘辨识

建立变形观测方程：

ΔX = A · c

其中：
ΔX  — 末端6D变形向量（测量值），维数 6m×1（m为测量构型数）
A   — 由雅可比矩阵和力矩构建的观测矩阵，维数 6m×p
c   — 待辨识柔度参数向量，维数 p×1（p为参数个数）

观测矩阵A的构建是关键：

A的第i行对应第i个测量点：
A[i] = J(θᵢ)ᵀ * diag(Jᵢ) * J(θᵢ)  （简化形式）

通过最小二乘求解柔度参数：

c = (AᵀA)⁻¹ · Aᵀ · ΔX

可进一步用加权最小二乘（WLS）提高鲁棒性，权重矩阵根据各测量方向的测量精度设定。

4.2 重力卸载法（无外加载荷）

不需要额外砝码，仅利用机械臂自重产生不同构型下的倾覆力矩差异。

核心思路：通过改变关节角度，改变各连杆自重对目标关节的力矩臂，从而在不同构型下产生不同的倾覆力矩，对比末端位姿差异辨识刚度。

操作流程：

选取一系列参考构型（J1固定，改变J2、J3），使大臂在不同仰角下工作。机械臂大臂俯仰角变化时，J1承受的倾覆力矩从0变化到最大值。记录对应的末端位姿偏差（相对于运动学模型预测值），即可建立倾覆力矩-变形的对应关系。

优点：无需额外加载设备，操作简便。

缺点：产生的倾覆力矩受自重限制，对于高刚度关节信噪比低；多关节同时变化时，各关节的贡献难以解耦，需要精心设计测试序列。

4.3 关节锁定单独辨识法

锁定其他关节，单独测量目标关节的倾覆响应。

对于大关节（J1、J2），可以通过控制伺服抱闸，使目标关节被动承受倾覆力矩（由剩余关节运动造成），再用激光跟踪仪测量关节输出端的倾斜角。关节输出端通常可以安装靶标支架，直接测量倾斜角度。

这种方法的辨识精度最高，但操作复杂（需要安装辅助靶标），且对于设备无锁定功能的机械臂难以实施。

4.4 辨识的可观测性分析

多参数辨识中常遇到的一个实际问题：某些参数组合在特定构型下不可观。

典型情形：当机械臂完全伸展（大臂水平）时，J1的倾覆力矩最大，但J2、J3的倾覆力矩差异相对较小，J2、J3倾覆刚度的辨识精度会下降。

可观测性定量评估：观测矩阵A的条件数（condition number）反映辨识问题的病态程度。条件数过大（>10³）时，建议：

增加测量构型（改善条件数）

对参数进行分组辨识（先辨识影响大的参数，再辨识次要参数）

对参数施加正则化约束（Tikhonov正则化）

五、倾覆方向的刚度补偿

辨识完刚度参数后，进入补偿实施阶段。

5.1 前馈补偿：预测-预补偿框架

补偿原理：在发出运动指令前，计算当前位姿和负载条件下各关节的倾覆力矩，预测末端倾覆变形，对目标位姿进行反向修正。

倾覆补偿量计算流程：

Step 1：输入 → 目标位姿 X_target，负载参数（质量m, 质心位置）
Step 2：逆运动学 → 计算关节角 θ_nominal
Step 3：静力学分析 → 计算各关节倾覆力矩 M_t_i
Step 4：变形预测 → Δθ_ti = M_t_i / K_t_i（各关节倾覆角变形）
Step 5：末端误差映射 → ΔX = J_tilt · [Δθ_t1, ..., Δθ_t6]
Step 6：补偿修正 → X_compensated = X_target - ΔX
Step 7：输出补偿后的指令到关节控制器

与扭转补偿的联合计算：

完整的前馈补偿需要同时考虑扭转变形（Δθ_torsion）和倾覆变形（Δθ_overturn），两者叠加：

ΔX_total = ΔX_torsion + ΔX_overturn

由于两类变形都依赖于构型（θ）和载荷（F），可以统一在笛卡尔柔度矩阵框架下处理，避免重复计算雅可比矩阵。

5.2 构形相关补偿表（LUT方案）

对于计算资源有限的控制器，可以离线构建补偿查找表（Look-Up Table）。

表格结构建议：

以6轴机械臂为例，完整的查找表需要6维索引（6个关节角），存储代价过高。工程中通常做如下简化：

关注对倾覆精度影响最大的前3关节（J1-J3）

构建3维补偿表：索引为（θ₁, θ₂, θ₃），存储6个方向的末端补偿量

以10°间隔采样（J1: 36点, J2: 18点, J3: 18点），总计约11,664个数据点

每个数据点存储6个浮点数（末端补偿量），内存约270KB（可接受）

在线插值：三维线性插值，计算量约为几百次乘加操作，满足1ms控制周期需求。

5.3 力反馈闭环修正（提高实时性）

前馈补偿依赖模型精度，对模型参数漂移（温度变化、磨损）不敏感。引入末端六维力传感器可以实现实时反馈修正。

修正策略：

实时估计倾覆力矩：
M_overturn_measured = T_sensor × d_lever   （传感器力矩 × 等效力臂）

实时修正补偿量：
ΔX_feedback = K_t⁻¹ × M_overturn_measured  （在线计算）

总补偿：
X_cmd = X_target + ΔX_feedforward + ΔX_feedback_correction

需要注意：力传感器坐标系需要标定（见上篇），否则力矩方向计算错误会使补偿效果变差甚至反向。

5.4 倾覆补偿与其他误差源的优先级

在多源误差补偿框架中，倾覆刚度补偿属于第二层（刚度层），应在DH参数标定（第一层）完成后进行。若第一层几何误差标定不彻底，倾覆刚度辨识的精度会受到污染（几何误差和弹性误差混叠）。

建议的补偿顺序：

① DH参数标定（关节零偏、连杆长度误差）
② 连杆自重重力补偿（扭转方向）
③ 倾覆方向刚度补偿（J1-J3为主）
④ 腕部关节扭转刚度补偿（J4-J6）
⑤ 热误差补偿（长时间运行场景）

按此顺序分层补偿，可以避免后一层的辨识受到前一层未补偿误差的干扰。有案例数据显示，完成全部4层补偿后，工业机器人铣削精度可从2mm级提升至0.2mm级，倾覆补偿单独贡献约0.4-0.6mm的精度改善（在大臂展、重载工况下）。

六、工程实践中几个值得注意的细节

关于辨识位形的选取：倾覆力矩最大（臂展最大、负载最重）的位形附近，倾覆变形信噪比最高，辨识精度最好。但这些位形也往往接近机械臂的极限工作状态，操作时注意安全余量。建议先在中等臂展下完成初步辨识，再在大臂展下验证和精化。

关于连杆自重的处理：连杆自重产生的倾覆力矩往往被忽略，但对于大型机器人（臂杆质量>10kg/节），自重贡献可能占总倾覆力矩的30-50%。若辨识时的构型与作业时的构型差异大，自重贡献的差异会直接带来补偿误差。建议辨识时尽量覆盖作业空间的典型构型，或显式建立连杆自重力矩模型。

关于轴承游隙的影响：新机器人的轴承游隙小，倾覆刚度线性度好，辨识精度高。使用2-3年后，轴承磨损会导致游隙增大，倾覆刚度下降并出现明显非线性。建议对长期使用的设备定期（每6-12个月）重新辨识倾覆刚度参数，并根据历史数据趋势评估轴承健康状态。

关于谐波减速器的特殊性：谐波减速器的波发生器-柔轮-刚轮结构决定了它的倾覆刚度具有角度周期性（与柔轮谐波次数相关），即随关节角度呈周期性变化。对于精度要求较高的场合，建议在倾覆刚度模型中加入角度相关项，而不是使用常数刚度假设。

关于协作机器人的特殊情况：协作机器人关节一般内置力矩传感器（或电流力矩估算），可以直接获取各关节的实时力矩信息，这为倾覆刚度的在线辨识提供了便利——可以在日常作业过程中持续积累数据，定期更新刚度参数，实现自适应补偿。传统工业机械臂无内置力传感器，只能依靠外部测量进行离线辨识。

七、总结

倾覆方向刚度补偿可以归纳为以下核心要点：

理解物理本质：倾覆变形由垂直于关节轴的弯矩引起，通过连杆放大后在末端产生位移+姿态误差，量级在0.3-1.5mm之间（重载大臂展），是不可忽视的精度瓶颈。

建模：从单DOF扭转虚关节扩展到多DOF关节弹性模型，每个关节增加2个倾覆柔度参数（两个垂直倾覆轴）。前3轴（腰部、大臂、小臂）是主要贡献者。

辨识：推荐静态加载+激光跟踪仪法，辨识精度最高；条件受限时可用重力卸载法。关注观测矩阵条件数，避免参数不可观的问题。

补偿：前馈预测补偿满足大多数工况需求；对于工况变化大（负载不确定、温度变化）的场景，结合六维力传感器实时修正效果更稳健。

分层实施：与DH几何标定、扭转刚度补偿、热误差补偿协同推进，按层级顺序实施，避免误差串扰。

倾覆刚度这个话题在文献和产品手册里着墨不多，但在大臂展重载场景的精度提升中，往往是"最后那0.5mm"的关键所在。希望上述梳理对有需要的工程师有所参考，也欢迎继续在留言区交流。
