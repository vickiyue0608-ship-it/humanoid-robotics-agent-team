# 机器人运动学与动力学：空间加速度

一、引言

在机器人运动学与动力学的研究中，速度螺旋（Twist）为描述刚体运动提供了一个统一的数学框架。在掌握了速度螺旋的概念之后，自然需要进一步探讨刚体运动状态的变化，这就引出了空间加速度（Spatial Acceleration）的概念。

空间加速度是速度螺旋对时间的导数，它描述了刚体速度场随时间的变化率。与速度螺旋类似，空间加速度也采用螺旋理论的框架，为机器人动力学分析和控制提供了简洁而强大的数学工具。

二、空间加速度的定义

2.1 从速度场到加速度场

刚体的运动可以用速度场来描述。在任意时刻，刚体上每一点都具有特定的速度，这些速度的集合构成了刚体的速度场。速度螺旋正是对这一速度场的紧凑表示。

当我们希望描述刚体速度的变化时，自然的想法是定义加速度来刻画速度场的变化率。因此，空间加速度被定义为速度螺旋对时间的导数：

A = dV/dt

其中，V表示速度螺旋，A表示空间加速度。

2.2 空间加速度的组成

与速度螺旋类似，空间加速度也由两个分量组成：

A = [α; A]ᵀ

•角加速度分量α：刚体角速度的导数，即α = dω/dt，这一分量的物理意义与传统定义完全一致。

•线加速度分量A：速度螺旋线速度分量的导数，但需要注意，A并不等于刚体上任何特定点的线加速度。

2.3 空间加速度与点加速度的区别

这是理解空间加速度的关键所在。为什么空间加速度的线速度分量不等于任何点的线加速度？

考虑以下情况：

1. t=0时刻：设刚体上的点P恰好与坐标系原点O重合。此时，速度螺旋的线速度分量v等于点P的线速度vₚ。

2. t=Δt时刻：经过微小时间Δt后，刚体发生了运动。此时与原点O重合的不再是点P，而是刚体上的另一点Q。

3.求导过程：速度螺旋在t=0时刻为V(0) = [ω(0); vₚ(0)]ᵀ，在t=Δt时刻为V(Δt) = [ω(Δt); vQ(Δt)]ᵀ。对速度螺旋求导：

dV/dt = lim(Δt→0) [V(Δt) - V(0)]/Δt = [dω/dt; (vQ - vₚ)/Δt]ᵀ

由此可见，空间加速度的线速度分量A描述的是在坐标系原点这一空间位置上，不同时刻经过此处的不同刚体点的速度变化率，即速度场本身的变化。

而某一特定点（如点P）的真实线加速度应该是：

aₚ = dvₚ/dt = d²rₚ/dt²

这是对该点位置的二阶导数，其物理意义与速度场的变化截然不同。

结论：空间加速度描述的是整个"运动模式"的变化，而不是某个"质点"的加速度。空间加速度的角加速度分量仍保持传统意义，但线加速度分量仅代表速度螺旋的导数，不代表任何特定点的线加速度。

三、空间加速度与点加速度的关系

尽管空间加速度的线速度分量不直接等于任何点的线加速度，但两者之间存在确定的数学关系。

对于刚体上任意一点P，其位置矢量为r，该点的线速度为：

vₚ = v₀ + ω × r

其中v₀是原点（或基点）的线速度。

对上式求导，得到点P的线加速度：

aₚ = dvₚ/dt = dv₀/dt + dω/dt × r + ω × dr/dt

注意到dr/dt = vₚ - v₀ = ω × r（这是相对速度），因此：

aₚ = A + α × r + ω × (ω × r)

这个公式揭示了空间加速度与点加速度的关系：

•第一项A是空间加速度的线速度分量

•第二项α × r是由角加速度产生的切向加速度

•第三项ω × (ω × r)是向心加速度

四、空间加速度的坐标变换

4.1 基本变换公式

在机器人学中，经常需要在不同坐标系之间转换速度和加速度。已知速度螺旋的坐标变换公式为：

V₀ = T · Vₐ

其中T是坐标变换矩阵（伴随变换矩阵）。

由于空间加速度是速度螺旋的导数，对上式两边求导即可得到加速度的变换公式：

A₀ = d/dt(T · Vₐ) = Ṫ · Vₐ + T · Aₐ

这里的关键在于计算Ṫ。根据螺旋理论，变换矩阵的导数可以表示为：

Ṫ = [Vₐ]× · T

其中[Vₐ]×是速度螺旋的叉乘矩阵形式。

因此，空间加速度的完整变换公式为：

A₀ = [Vₐ]× · T · Vₐ + T · Aₐ

或者写成更紧凑的形式：

A₀ = [Vₐ]× · V₀ + T · Aₐ

4.2 复合运动的加速度

考虑一个更实际的问题：刚体B相对于坐标系A运动，而坐标系A又相对于地面坐标系O运动。如何求刚体B在地面坐标系O下的加速度？

已知条件：

•坐标系A相对于O的位置矩阵：Pₐ

•坐标系A相对于O的速度螺旋：Vₐ/₀（在O系下表示）

•坐标系A相对于O的加速度螺旋：Aₐ/₀（在O系下表示）

•刚体B相对于A的速度螺旋：Vᵦ/ₐ（在A系下表示）

第一步：求B在O系下的速度

Vᵦ/₀ = Vₐ/₀ + Tₐ₀ · Vᵦ/ₐ

第二步：求B在O系下的加速度

对速度公式求导：

Aᵦ/₀ = dVₐ/₀/dt + d/dt(Tₐ₀ · Vᵦ/ₐ)

情况1：B相对于A作匀速运动（Vᵦ/ₐ不变）

Aᵦ/₀ = Aₐ/₀ + [Vₐ/₀]× · Tₐ₀ · Vᵦ/ₐ

情况2：B相对于A有加速度（Vᵦ/ₐ变化）

Aᵦ/₀ = Aₐ/₀ + [Vₐ/₀]× · Tₐ₀ · Vᵦ/ₐ + Tₐ₀ · Aᵦ/ₐ

这一公式包含三项：

1. Aₐ/₀：坐标系A自身的加速度

2. [Vₐ/₀]× · Tₐ₀ · Vᵦ/ₐ：由于坐标系A的运动与B相对A的速度耦合产生的附加项

3. Tₐ₀ · Aᵦ/ₐ：B相对A的加速度在O系下的表示

对比传统方法：

使用传统的点加速度方法推导上述结果需要：

•定义多个坐标系（惯性系、动系等）

•对位置矢量进行二阶求导

•处理速度耦合产生的科里奥利项

•推导过程冗长且容易出错

而使用螺旋理论，推导过程清晰简洁，仅需对速度螺旋的变换公式求导即可。

五、雅可比矩阵的导数（J̇）

5.1 问题的提出

在机器人运动学中，雅可比矩阵J建立了关节速度与末端执行器速度之间的关系：

V = J · q̇

其中q是关节角度向量，q̇是关节速度向量。

为了得到加速度级的运动学关系，需要对上式求导：

A = J · q̈ + J̇ · q̇

这里出现了雅可比矩阵的导数J̇。在传统方法中，求解J̇是一个极其繁琐且容易出错的过程，许多机器人工程师在这一步骤上遇到困难。

5.2 基于螺旋理论的求解方法

螺旋理论为求解J̇提供了极其简洁的方法。

雅可比矩阵的每一列Jᵢ代表第i个关节的速度螺旋：

J = [V₁ V₂  ⋯  Vₙ]

对于串联机器人，第i个关节的速度螺旋可以表示为：

Vᵢ = Tᵢ · Vᵢ₀

其中Vᵢ₀是该关节在初始配置下的速度螺旋，Tᵢ是从初始配置到当前配置的坐标变换。

对Vᵢ求导：

V̇ᵢ = Ṫᵢ · Vᵢ₀ + Tᵢ · V̇ᵢ₀

由于速度螺旋固定在连杆上，Vᵢ₀是常量，因此V̇ᵢ₀ = 0。同时：

Ṫᵢ = [V_link(i)]× · Tᵢ

其中V_link(i)是承载第i个关节的连杆的速度螺旋。

因此：

V̇ᵢ = [V_link(i)]× · Tᵢ · Vᵢ₀ = [V_link(i)]× · Vᵢ

这就得到了雅可比矩阵导数的每一列：

J̇ᵢ = [V_link(i)]× · Jᵢ

完整的雅可比矩阵导数为：

J̇ = [[V_link(1)]× · J₁ [V_link(2)]× · J₂  ⋯  [V_link(n)]× · Jₙ]

5.3 算法步骤

已知条件：

•当前各关节的单位速度螺旋Vᵢ₀（在求雅可比矩阵时已计算）

•当前各连杆的速度螺旋V_link(i)（可通过速度传递关系计算）

计算步骤：

步骤1：计算当前配置下的雅可比矩阵

Jᵢ = Tᵢ · Vᵢ₀, i = 1, 2, …, n

步骤2：计算各连杆的速度螺旋

对于第i个连杆（固定在地面的第0个连杆除外）：

V_link(i) = Σⱼ₌₁ⁱ Jⱼ · q̇ⱼ

步骤3：计算雅可比矩阵的导数

J̇ᵢ = [V_link(i)]× · Jᵢ, i = 1, 2, …, n

示例：对于一个2自由度串联机器人

•连杆0（基座）：固定在地面，V_link(0) = 0

•连杆1：由关节1驱动，V_link(1) = J₁ · q̇₁

•关节1的速度螺旋导数：J̇₁ = [V_link(0)]× · J₁ = 0（因为连杆0固定）

•连杆2：由关节1和关节2共同驱动，V_link(2) = J₁ · q̇₁ + J₂ · q̇₂

•关节2的速度螺旋导数：J̇₂ = [V_link(1)]× · J₂ = [J₁ · q̇₁]× · J₂

因此：

J̇ = [0 [J₁ · q̇₁]× · J₂]

5.4 方法优势

传统方法求解J̇的困难：

•需要对雅可比矩阵的每个元素进行符号求导

•涉及大量三角函数的导数

•公式冗长，容易出现计算错误

•验证结果正确性困难

螺旋理论方法的优势：

•公式简洁：J̇ᵢ = [V_link(i)]× · Jᵢ

•计算效率高：只需进行叉乘运算

•物理意义清晰：直接从速度螺旋的微分得出

•易于实现和验证
